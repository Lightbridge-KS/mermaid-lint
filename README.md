# mermaid-lint

Lint Mermaid diagrams in Markdown with the real Mermaid parser. Built for AI coding
agents that must check a diagram they cannot see.

Status: in development. See the [design](docs/design/01-mermaid-lint-design.md) and
the [progress overview](docs/progress/overview-v0.1.md).
